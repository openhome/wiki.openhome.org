# <span id="ohSpy"></span>ohSpy

OpenHome has begun developement of a tool which can be run to show any UPnP connected devices on a network. This is an equivalent to Intel's Device Spy.

More detail on this can be found [here](http://software.intel.com/en-us/articles/intel-software-for-upnp-technology-technology-overview).

OpenHome in interested in those wishing to contribute to completing the ohSpy project.
